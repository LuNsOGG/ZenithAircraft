# Aplicación de escritorio de SixPack

Carpeta reservada para el desarrollo futuro de la aplicación que visualizará y graficará los datos de vuelo registrados por Zenith.

Alcance previsto: lectura de registros, gráficas, instrumentos y conexión serial. No hay todavía una aplicación implementada en esta carpeta ni una tecnología elegida.

Los formatos compartidos se definirán en [protocols/](../../protocols/README.md); los registros de ejemplo se ubicarán en [data/examples/](../../data/examples/README.md).
