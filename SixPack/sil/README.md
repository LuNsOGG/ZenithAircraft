## Pruebas de desarrollo

Con Node.js 18 o posterior, ejecuta desde esta carpeta:

```sh
node tests/run-tests.cjs
```

También puedes ejecutar `node SixPack/sil/tests/run-tests.cjs` desde la raíz del repositorio. No requiere paquetes adicionales. La aplicación y sus pruebas se conservan sin cambios de lógica tras la reorganización.
