# Información de Zenith

Carpeta preparada para documentar arquitectura del firmware, conexiones, configuración de placas, adquisición de sensores, procesamiento, registro y pruebas.

Objetivos de hardware: STM32F407VET6 como controlador principal y STM32F411 Black Pill para prototipos. Los proyectos todavía están pendientes de implementación.

Las decisiones sobre mensajes seriales y archivos de vuelo deben compartirse en [protocols/](../../../protocols/README.md).
