# Firmware principal: STM32F407VET6

Carpeta reservada para el proyecto del controlador principal. Guarda aquí su configuración, código específico y futuros archivos del entorno de desarrollo.

Todavía no hay firmware implementado. Antes de configurar el proyecto deben verificarse la placa, la variante del microcontrolador y su asignación de pines. Las referencias existentes incluyen nombres STM32F407VGT6 y no constituyen una validación de la variante VET6.

El código reutilizable podrá ubicarse en [../shared/](../shared/README.md).
