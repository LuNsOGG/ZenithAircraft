# Hardware de Zenith

Carpeta para esquemáticos, PCB, conexiones y referencias de componentes.

El contenido previo de `ZenithV3/` se conserva íntegro en [referencias/ZenithV3/](referencias/ZenithV3/), incluidos los nombres originales de imágenes y PDF y la subcarpeta local vacía `ZenithAircraft/`. Git no registra carpetas vacías por sí solo.

Las referencias incluyen nombres de STM32F407VGT6 y STM32F407VET6. Se preservan tal como estaban; la variante principal prevista del proyecto es STM32F407VET6. Verifica la correspondencia de cada referencia antes de usarla para conexiones o diseño.

Los reportes y guías técnicas de Zenith se guardan en [../docs/](../docs/README.md).
