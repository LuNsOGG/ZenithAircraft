# Contratos de datos compartidos

Carpeta para definir la comunicación entre Zenith y SixPack y el formato de los registros de vuelo. Todavía no hay un protocolo implementado o aprobado.

La definición futura deberá especificar campos, unidades, marcas de tiempo, identificación de origen, validez de sensores, encuadre de mensajes, versión y tratamiento de datos incompletos o perdidos.

El objetivo es que el firmware, los datos de prueba del SIL y la aplicación de escritorio utilicen formatos compatibles. La propuesta previa de protocolo SP1 no se considera implementada por crear esta carpeta.
